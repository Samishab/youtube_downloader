# YouTube Downloader

تطبيق سطح مكتب لتحميل فيديوهات يوتيوب — فيديو واحد أو قناة كاملة — بواجهة رسومية عربية.

| المتطلب | الإصدار | ملاحظة |
|---------|---------|--------|
| Python | 3.9+ | [تحميل](https://www.python.org/downloads/) |
| ffmpeg | أي إصدار | **مطلوب** لدمج الفيديو والصوت — راجع التثبيت أدناه |

---

## تثبيت ffmpeg

> **مهم:** بدون ffmpeg لن يعمل تحميل جودة 1080p/720p بشكل صحيح، ولن يعمل استخراج الصوت MP3.

### Windows
1. حمّل النسخة من [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) (اختر `ffmpeg-release-essentials.zip`)
2. فك الضغط وانسخ مجلد `bin` إلى مكان ثابت مثل `C:\ffmpeg\bin`
3. أضف `C:\ffmpeg\bin` إلى متغير البيئة `PATH`:
   - ابحث عن "تعديل متغيرات البيئة" في قائمة ابدأ
   - افتح `Path` ← `تعديل` ← أضف المسار

للتأكد من التثبيت:
```
ffmpeg -version
```

### macOS
```bash
brew install ffmpeg
```

### Linux
```bash
sudo apt install ffmpeg
```

## تشغيل البرنامج

```bash
# 1. استنساخ المشروع
git clone https://github.com/Samishab/youtube_downloader.git
cd youtube_downloader

# 2. تثبيت المكتبات
pip install -r requirements.txt

# 3. تشغيل التطبيق
python app.py
```

> المكتبات `yt-dlp` و `customtkinter` تُثبَّت تلقائياً عند أول تشغيل إن لم تكن موجودة.

## الميزات

- **فيديو واحد أو قناة/قائمة تشغيل** — الصق أي رابط يوتيوب
- **قائمة الفيديوهات** — عنوان، مدة، حجم مقدَّر لكل فيديو
- **اختيار ما تريد تحميله** — تحديد أو إلغاء تحديد كل فيديو بضغطة
- **تحذير الحجم** — يعرض الحجم الكلي قبل البدء ويطلب تأكيدك
- **خيارات الجودة** — أفضل جودة / 1080p / 720p / 480p / 360p / صوت MP3
- **تقدم التحميل** — شريط تقدم + سرعة + وقت متبقي
- **إيقاف في أي وقت** — زر إيقاف أثناء التحميل
- **مجلد الحفظ** — اختر أي مجلد من داخل التطبيق
